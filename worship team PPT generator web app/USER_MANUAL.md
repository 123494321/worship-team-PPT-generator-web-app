# 📖 LOGOS 찬양 PPT 제작 스튜디오 공식 설명서 (v2.0)

> **"콘티 입력 ➔ 실시간 16:9 미리보기 ➔ 단 1초 만에 교회 표준 16:9 와이드 찬양 PPT 완성!"**  
> 본 시스템은 번거로운 설정 없이 표준 양식 PPTX 파일과 16:9 예배 표지를 바탕으로 찬양 PPT를 자동 생성하는 현대적인 웹 스튜디오입니다.

---

## ⚡ [1부] 3분 완성 퀵 스타트 가이드

```mermaid
flowchart LR
    S1["1. 콘티 입력<br/>(에디터)"] --> S2["2. 16:9 슬라이드<br/>실시간 미리보기"]
    S2 --> S3["3. [PPT 생성]<br/>버튼 클릭 (1초)"]
    S3 --> S4["4. 완성본 PPTX<br/>즉시 다운로드"]
```

---

### Step 1. 콘티 입력
* 중앙의 **찬양 콘티 에디터**에 콘티를 붙여넣거나 직접 작성합니다.
* 사이드바의 **`[콘티 파일]`** 버튼을 통해 PC의 `.txt`, `.md` 파일을 불러오거나 드래그하여 즉시 적용할 수 있습니다.
* **작성 기본 규칙:**
  1. 예배 날짜/모임명: 맨 첫 줄에 `# 2026.09.20 LOGOS 청년 찬양 모임` 형태로 작성
  2. 대표기도자: `기도: 홍길동 청년`
  3. 곡 시작: `## 1. 곡 제목`
  4. 슬라이드 분할: **가사 문장 사이를 한 줄 띄우면(엔터 2번)** 자동으로 다음 슬라이드로 분할됩니다.

### Step 2. 실시간 16:9 미리보기 확인
* 우측의 **실시간 16:9 슬라이드 카드** 영역에서 표지, 곡 제목(`[곡 제목]`), 가사 자막, 암전, 대표기도 슬라이드가 즉시 렌더링됩니다.
* 카드를 클릭하면 **대형 모달 화면**으로 꽉 차게 확인할 수 있으며, 키보드 방향키(`←`/`→`) 또는 화면 버튼으로 슬라이드를 넘겨볼 수 있습니다.

### Step 3. [PPT 생성] 버튼 클릭 및 다운로드
* 우측 상단의 **`[PPT 생성 (16:9 와이드)]`** 버튼을 누르면 1초 만에 표준 PPTX 파일이 빌드되고, 브라우저를 통해 즉시 다운로드됩니다.
* 다운로드된 파일은 `data/pptx/` 폴더에도 안전하게 백업 보관됩니다.

---

## 📚 [2부] 상세 기능 및 콘티 작성 문법

### 1. 표지 이미지 관리
* 사이드바의 **`[표지 이미지]`** 버튼을 누르면 예배 표지를 변경할 수 있습니다.
* 16:9 비율의 이미지(`.png`, `.jpg`, `.jpeg`, `.webp`)를 끌어다 놓거나 `[파일 탐색기 열기]` 버튼을 눌러 등록합니다.
* `[초기화]` 버튼을 누르면 언제든 기본 표지로 되돌릴 수 있습니다.
* 등록된 표지는 `data/covers/`에 안전하게 보관됩니다.

### 2. 콘티 필수 작성 문법
| 구분 | 문법 규칙 | 작성 예시 | 동작 결과 |
| :--- | :--- | :--- | :--- |
| **표지 정보** | `# [날짜] [모임명]` | `# 2026.09.20 LOGOS 청년 찬양 모임` | 1페이지 표지 슬라이드 자동 생성 |
| **대표기도자** | `기도: [이름]` | `기도: 홍길동 청년` | 찬양 종료 후 마지막 대표기도 슬라이드 생성 |
| **곡 시작** | `## [번호]. [곡 제목]` | `## 1. 꽃들도` | 곡 시작 선언 및 제목 슬라이드(`[꽃들도]`) 생성 |
| **악보 루틴** | `루틴: [진행 순서]` | `루틴: Intro(8) - V1 - C - C - Outro` | 악보 순서에 맞춰 가사 슬라이드를 순방향 자동 전개 |
| **파트 선언** | `[파트명]` | `[V]`, `[P]`, `[C]`, `[B]` | 절(Verse), 프리코러스, 후렴, 브릿지 등 파트 선언 |
| **슬라이드 분할**| **빈 줄 하나 (엔터 2번)** | *(가사 문장 사이 빈 줄)* | **빈 줄이 들어가면 다음 슬라이드로 넘어감** |

### 3. 디렉토리 구조
* **`assets/master_template.pptx`**: Pretendard 폰트가 내장된 공식 16:9 마스터 템플릿 파일
* **`data/covers/`**: 사용자가 등록한 16:9 예배 표지 이미지 보관소
* **`data/pptx/`**: 생성된 주차별 찬양 PPTX 완성본 백업 저장소
* **`server/`**: 경량화된 고속 FastAPI 백엔드
* **`client/`**: React 18 + Tailwind CSS 기반 초경량 프론트엔드 스튜디오
